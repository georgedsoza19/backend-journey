# Phase 1 — Foundations

**Time:** 2–3 weeks @ 12–15 hrs/week  
**App:** `apps/phase-01-cli-todo`

## Learn

- Node.js runtime, ESM, async I/O, env vars
- TypeScript for backends (`strict`, `tsx`)
- Raw `http` servers before Express

## Resources

- [Node.js Learn](https://nodejs.org/learn)
- [TypeScript for JS Programmers](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html)
- [Microsoft Beginner’s Series to Node.js](https://learn.microsoft.com/en-us/shows/beginners-series-to-nodejs/)

## Exercises in this repo

1. CLI todo backed by `data/todos.json`
2. HTTP JSON API with GET/POST/PATCH/DELETE
3. Both under TypeScript strict mode

## Milestone

You can start a typed Node process, parse env vars, handle async file I/O, and serve JSON without Express.
