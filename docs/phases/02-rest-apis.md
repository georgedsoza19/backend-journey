# Phase 2 — HTTP, REST & Express

**Time:** 3–4 weeks @ 12–15 hrs/week  
**App:** `apps/phase-02-taskboard-api`

## Learn

- HTTP methods, status codes, headers, CORS (concept)
- REST resources, pagination, filtering
- Express routing, middleware, routers
- Zod validation at the boundary
- Structured error responses

## Resources

- [MDN HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview)
- [MDN REST](https://developer.mozilla.org/en-US/docs/Glossary/REST)
- [Express Guide](https://expressjs.com/en/guide/routing.html)
- [Zod](https://zod.dev/)

## Exercises in this repo

1. Design `/tasks` as a REST resource
2. Validate create/update/list with Zod
3. Return consistent error JSON from one middleware

## Milestone

Given a resource, you can design routes and status codes, and ship a validated Express API with `routes/`, `controllers/`, `middleware/`, and `schemas/`.
