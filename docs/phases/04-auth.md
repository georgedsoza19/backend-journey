# Phase 4 — Auth & first Next.js UI

**Apps:** `phase-04-secure-notes-api` + `phase-04-secure-notes-web`

## Learn

- Hashing passwords; never store plaintext
- JWT access + refresh rotation
- Ownership checks (anti-IDOR) and RBAC
- CORS for a real browser client
- Next.js App Router consuming a separate Express API

## Milestone

Draw the auth flow, log in as Alice and Admin, and confirm users cannot edit each other’s notes while admins can use `scope=all`.
